# Online Retail Data Analytics Dashboard

## Project Overview

This project is an Online Retail Data Analytics Dashboard developed as part of my internship project.

The main objective of this project is to analyze online retail transaction data and identify meaningful patterns related to customers, products, sales, and geographical distribution.

## Features

- Dataset Overview
- Data Cleaning
- Customer Analysis
- Sales Analysis
- Product Analysis
- Interactive Dashboard
- Key Business Insights

## Key Metrics

The dashboard provides important metrics such as:

- Total Sales
- Unique Customers
- Unique Products
- Number of Countries

## Technologies Used

- Python
- Pandas
- Streamlit

## Project Files

- `app.py` – Main Streamlit application
- `retail_sample.csv` – Dataset used for analysis
- `requirements.txt` – Required Python libraries
